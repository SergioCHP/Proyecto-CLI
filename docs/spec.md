# Spec de navaja

La spec de 10 puntos está en el README, en la sección
[Spec](../README.md#spec), para que quien instale navaja la lea lo primero.
Aquí solo se enlaza, para no tenerla repetida en dos sitios y que se desactualice.

Lo que cubre:

1. Problema que se repite.
2. Para quién.
3. Uso.
4. Órdenes que ya tiene.
5. Órdenes previstas.
6. Acciones.
7. Lo que nunca hará.
8. Plataformas.
9. Códigos de salida.
10. Instalación.

Cómo se escribió (lo respondí yo y el agente solo lo ordenó): [prompts.md](prompts.md).
